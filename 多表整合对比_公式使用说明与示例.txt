多表整合对比——公式使用说明与示例
适用版本：2026年10月16日当前代码

一、在哪里填写公式

1. 上传主表和对照表，选择需要使用的工作表。
2. 配置各张表的关联键，例如“工号”。关联键用于确定哪些记录属于同一人。
3. 在“覆盖字段”区域，勾选需要回填的主表列。
4. 点击对应的来源单元格，勾选来源字段，在“联合公式”框中编辑公式并确认。
5. 执行整合，检查回填结果和差异报告。

也可在“联合公式”上方的“公式描述”中写明判断条件、取值来源、优先级和未匹配时的处理，点击“生成公式”。多表整合对比和拆表的列公式均支持。
“AI公式描述与生成”默认折叠；展开后描述框约10行高，可拖动调高，最多输入20000字。可在“预期结果/核对示例”中补充最多8000字的期望结果或边界示例，两项均随方案保存。
AI按本工具内置公式规则生成，不直接套用标准Excel公式；生成结果先做语法校验，确认后才应用。信息不足或内置规则不能准确实现时，会提示补充说明。
生成时结合目标/来源文件名、Sheet名、多层表头、关联键、字段类型和非空率摘要、当前公式、数据范围及你输入的描述与预期结果，不自动发送员工明细。生成过程中手工修改的内容会保留，取消弹窗不会应用生成结果。
本功能针对列的联合公式；拆表的“分组表达式”有另外一套语法，不应混用函数。

建议通过勾选字段插入列名，不要凭记忆手输文件名和列名。
下面的文件名、列名均为示例，实际使用时请替换为页面显示的名称。

二、公式的基本写法

1. 列名引用
   当前默认对照表的字段可以直接使用列名，例如：
   基本工资+补贴-扣款

2. 跨表引用
   使用“文件名.列名”，例如：
   工资表.xlsx.基本工资+补贴表.xlsx.补贴

   如果文件包含多个 Sheet，页面可能生成类似下面的表名：
   工资表__9月.xlsx
   对应的引用示例：
   工资表__9月.xlsx.基本工资

   请保留页面自动插入的完整名称，不要自行改成 Sheet1!A2 等写法。

3. 书写规则
   - 开头的等号可写可不写，例如 ROUND(金额,2) 和 =ROUND(金额,2)。
   - 函数名不区分大小写，建议统一大写。
   - 参数之间使用英文逗号 ,。
   - 使用英文括号 ( )，可以嵌套函数和括号。
   - 文本常量使用英文双引号，例如 "一致"。
   - 百分比请写成小数，例如 0.1 表示 10%；不要直接写 10%。
   - 一条联合公式需要引用至少一个有效来源字段，不用于单独填写常量公式。

三、支持的运算符

四则运算：+（加）、-（减）、*（乘）、/（除）
比较运算：=（等于）、<>（不等于）、>、>=、<、<=
文本拼接：&
括号分组：( )

示例1：计算实发金额
公式：基本工资+补贴-扣款
数据：基本工资5000，补贴300，扣款100。
结果：5200。

示例2：按计薪天数折算工资
公式：ROUND((基本工资+补贴)/应出勤天数*计薪天数,2)
数据：基本工资5000，补贴280，应出勤天数22，计薪天数20。
结果：4800。

示例3：拼接姓名和部门
公式：姓名&" / "&部门
数据：姓名为张三，部门为财务部。
结果：张三 / 财务部。
说明：文本拼接使用 &，不要用 + 代替。

四、支持的9个函数及示例

1. ROUND——四舍五入
   写法：ROUND(数值,小数位数)
   示例：ROUND(金额,2)
   数据：金额为123.456。
   结果：123.46。
   补充：省略第二个参数时按整数四舍五入；小数位数支持-15到15。

2. IF——条件判断
   写法：IF(条件,满足条件时的结果,不满足条件时的结果)
   示例：IF(计薪天数>=应出勤天数,200,0)
   数据：计薪天数22，应出勤天数22。
   结果：200。
   说明：本功能的 IF 请完整填写三个参数。

3. ABS——取绝对值
   写法：ABS(数值)
   示例：ABS(本月金额-上月金额)
   数据：本月金额4800，上月金额5000。
   结果：200。

4. MIN——取最小值
   写法：MIN(数值1,数值2,...)
   示例：MIN(报销金额,500)
   数据：报销金额650。
   结果：500，即最高按500计算。

5. MAX——取最大值
   写法：MAX(数值1,数值2,...)
   示例：MAX(基本工资+补贴-扣款,0)
   数据：基本工资100，补贴0，扣款150。
   结果：0，即计算结果最低为0。

6. SUM——多个数值相加
   写法：SUM(数值1,数值2,...)
   示例：SUM(基本工资,补贴,奖金)
   数据：基本工资5000，补贴300，奖金500。
   结果：5800。
   说明：这里填字段或表达式，不支持 SUM(A2:A100) 这样的范围引用。

7. AND——全部条件都满足
   写法：AND(条件1,条件2,...)
   示例：IF(AND(计薪天数>=应出勤天数,迟到次数=0),200,0)
   数据：计薪天数22，应出勤天数22，迟到次数0。
   结果：200；任一条件不满足时为0。

8. OR——任意一个条件满足
   写法：OR(条件1,条件2,...)
   示例：IF(OR(加班小时>0,节假日加班小时>0),100,0)
   数据：加班小时0，节假日加班小时8。
   结果：100；两个条件都不满足时为0。

9. NOT——条件取反
   写法：NOT(条件)
   示例：IF(NOT(扣款>0),100,0)
   数据：扣款0。
   结果：100；扣款大于0时为0。

五、常用业务公式

1. 跨表计算实发金额，保留两位小数
   ROUND(工资表.xlsx.基本工资+补贴表.xlsx.补贴-扣款表.xlsx.扣款,2)

2. 核对两张表的金额，允许相差不超过0.01
   IF(ABS(本月表.xlsx.实发金额-核算表.xlsx.应发金额)<=0.01,"一致","有差异")
   示例：两边分别为5200和5200，结果为“一致”。
   注意：请先核查关联键是否匹配，不能把缺失来源当成真实的零金额。

3. 避免应出勤天数为0导致除零
   IF(应出勤天数=0,0,ROUND(基本工资/应出勤天数*计薪天数,2))
   示例：应出勤天数为0时结果为0，不执行除法分支。

4. 比例补贴，最高300、最低0
   MAX(MIN(ROUND(计薪天数*15,2),300),0)
   示例：计薪天数22，原计算值330，最终结果为300。

5. 金额分档
   IF(业绩>=100000,1000,IF(业绩>=50000,500,0))
   示例：业绩60000，结果为500。

6. 跨表拼接人员信息
   人员表.xlsx.姓名&" / "&组织表.xlsx.部门
   示例：姓名为张三，部门为财务部，结果为“张三 / 财务部”。

六、必须了解的计算规则

1. 先按关联键匹配，再执行公式
   例如关联键是“工号”，系统对主表每一行，读取各来源表同工号的记录进行计算。
   不会按上传文件中的行号直接对齐。

2. 同一关联键有多行时，数值列先分别求和，再代入公式
   例如同一工号有两行：
   第1行：金额100，数量2。
   第2行：金额200，数量3。
   公式“金额*数量”的结果为：(100+200)*(2+3)=1500。
   它不是逐行计算后再相加，不会得到100*2+200*3=800。

   同理，MAX(金额,500) 比较的是汇总金额300和500，结果为500。
   它不是从原始明细中查找最大单笔金额。

3. 文本取值
   直接引用文本列或使用 & 拼接时，取同一关联键下该列首个非空值。
   不会把该工号所有行的姓名或备注自动串接起来。
   姓名和部门分别取各列的首个非空值，可能来自同一工号的不同记录。

4. 文本条件判断的限制
   当前列引用主要按数值语义参与条件和算术计算。
   文本判断应明确转为文本，例如 IF((部门&"")="财务部",200,0)。不要直接写 IF(部门="财务部",200,0)，否则文本列可能按0参与条件。
   IF 的结果分支可以返回文本，例如 IF(金额>0,"有金额","无金额")。
   返回文本字段时也应明确转为文本，例如 IF(金额>0,(银行卡号&""),"")，避免长银行卡号、证件号被转换成0。

5. 缺失与空值
   数值公式中，部分引用没有匹配行或全部为空时，该部分按0参与计算。
   所有引用都没有有效值时，公式返回空结果，不会仅计算常量或 IF 的兜底分支。
   普通单列未命中通常保留主表原值；带运算的公式返回空结果时，目标格可能被清空。
   因此，应结合匹配情况核查结果，不能仅凭结果为0判断数据正常。

6. 除零和不合法公式
   除零或不合法表达式会产生空结果，不能依赖 Excel 错误值继续计算。
   需要避免除零时，请使用前面的 IF 示例。

7. 回填的是计算值
   联合公式在系统中计算后，把结果值写入勾选的目标列。
   不会把这段联合公式写成目标单元格中的 Excel 公式。
   主表其他未覆盖位置的已有公式和格式按整合输出逻辑保留。

8. 主表原值参与计算
   启用“主键捏合”模式时，可把模板原值作为公式来源。
   页面可能自动把模板目标列原值加入公式，请检查可见公式，避免重复相加。
   普通模式下请使用页面提供的可选来源字段。

七、目前不支持的公式和写法

以下指“联合公式”输入框的支持范围，不代表上传工作簿原有公式的全部能力。

不支持的常见函数：
VLOOKUP、XLOOKUP、HLOOKUP、INDEX、MATCH；
SUMIF、SUMIFS、COUNT、COUNTA、COUNTIF、COUNTIFS、AVERAGE；
IFERROR、IFNA、IFS；
LEFT、RIGHT、MID、LEN、TEXT、CONCAT、TEXTJOIN；
DATE、YEAR、MONTH、DAY、TODAY、NOW等日期函数。

不支持的引用和运算写法：
A2、$A$2、A2:A100、Sheet1!A2等单元格和区域引用；
^（乘方）、%（百分号）、使用分号分隔函数参数。

替代方式：
- 查找匹配：在页面配置关联键，选择需要回填的来源列。
- 同一关联键下的金额汇总：直接引用金额列，系统自动跨行求和。
- 文本拼接：使用 &。
- 防止除零：使用 IF(分母列=0,0,分子列/分母列)。
- 复杂功能：先在来源文件中计算出辅助列，再选择该辅助列参与整合。

八、快速检查清单

执行前：
[ ] 主表与对照表的关联键是否正确？
[ ] 文件名、Sheet对应的表名、列名是否与页面一致？
[ ] 公式使用的逗号、括号、双引号是否为英文符号？
[ ] 是否只使用当前支持的9个函数和运算符？
[ ] 是否存在同一关联键多行，且“先汇总再计算”符合业务规则？
[ ] 除法公式是否处理了分母为0的情况？

执行后：
[ ] 抽查已匹配、未匹配、多行记录对应的计算结果。
[ ] 检查差异报告，确认来源缺失没有被误认为真实的零金额。
[ ] 检查被覆盖的目标列，确认空值、文本和金额符合预期。
